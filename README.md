# Missão Ingredientes Perdidos

Jogo do Rei da Farinha: recolha os ingredientes certos de cada receita, fuja dos ratos e volte à padaria antes do forno esfriar.

- 3 fases: Pão Francês, Bolo Caseiro e Pão de Queijo
- Ingrediente certo: +100 pontos. Ingrediente errado: −5 segundos.
- Rato pegou: perde uma vida e ele leva um ingrediente.

**Controles:** setas ou WASD no computador; no celular, arraste o dedo sobre o campo. `P` pausa.

Para jogar, basta abrir `index.html` no navegador (um único arquivo, sem instalação).
